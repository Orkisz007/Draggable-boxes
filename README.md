# Draggable boxes

The project was first created to test the ways to drag divs for another project,
as the method I usually found wasn't satisfying my needs.
It has later become its own thing after I had showed what I had done to my friends
and they suggested making something like this.

I thought about this project for some time and decided to add even more features
than my friends suggested and that's how we got here.

I hope you will enjoy what I made and maybe that it will help you if you need something
similar to this.
